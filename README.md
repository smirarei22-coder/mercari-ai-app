# 出品AIアシスタント：無料ChatGPT連携版

## GitHub上の既存アプリを更新する方法
1. ZIPを解凍します。
2. GitHubの既存リポジトリ mercari-ai-app を開きます。
3. Add file → Upload files から、このフォルダ内の7ファイルをアップロードします（ZIPそのものではありません）。
4. 同名ファイルを上書きする変更を確認し、Commit changes を押します。
5. GitHub Pages の公開が完了したらアプリを再読み込みします。古い表示が残る場合はChromeでページを再読み込みしてください。

## 無料で使う
写真を選ぶ → 無料でChatGPTを使う → 依頼文をコピー → ChatGPTを開いて同じ写真を添付し依頼文を送信 → ChatGPTの回答をコピー → アプリに貼り付け → 回答を反映 → 相場検索と保存。

ChatGPTへ写真は自動転送されません。ChatGPT無料プランの画像アップロードには利用制限があります。メルカリの売却済み価格は自動取得しません。履歴は端末内に保存され、ブラウザデータ削除で消えることがあります。

APIキー不要・追加API料金不要。旧来の有料Worker接続も任意で残しています。
